🏥 Example 1: ECG Signal Analysis

Analyze electrocardiogram (ECG) signals to extract heartbeat components and detect anomalies. EMD separates the signal into IMFs representing different physiological processes: IMF 1 captures high-frequency noise and small oscillations, IMF 2-3 contain the main heartbeat components, and the Residual shows the overall trend and baseline drift.

📊 EMD Decomposition Visualization
From top to bottom: Original ECG signal showing the raw heartbeat pattern → IMF 1 (high-frequency components) → IMF 2 (mid-frequency cardiac pulses) → IMF 3 (slower oscillations) → Residual (overall trend and drift).
PythonCopyimport numpy as np from ferromode import EMD import csv # Load ECG data from CSV file ecg_data = [] with open('data/ecg_sample.csv') as f: reader = csv.DictReader(f) for row in reader: ecg_data.append(float(row['signal'])) signal = np.array(ecg_data) # Configure EMD decomposition parameters emd = EMD( max_imf=5, # Maximum 5 IMFs stopping_criteria=0.2 # Energy-based stopping ) # Perform EMD decomposition imfs = emd.decompose(signal) # Analyze the results print(f"Original signal: {len(signal)} samples") print(f"Number of IMFs: {len(imfs)}") # Extract heartbeat rate from first IMF heartbeat_imf = imfs[0] peaks = np.where(np.diff(np.sign(np.diff(heartbeat_imf))) == -2)[0] heartbeat_rate = len(peaks) / (len(signal) / 1000) print(f"Estimated heart rate: {heartbeat_rate:.1f} bpm") # Calculate energy distribution across IMFs for i, imf in enumerate(imfs): energy = np.sum(imf ** 2) print(f"IMF {i} energy: {energy:.4f}")
RustCopyuse ferromode::EMD; use std::fs::File; use csv::Reader; fn main() -> Result<(), Box<dyn std::error::Error>> { // Load ECG data from CSV let mut reader = Reader::from_path("data/ecg_sample.csv")?; let mut signal = Vec::new(); for record in reader.records() { let record = record?; let value: f64 = record[1].parse()?; signal.push(value); } // Configure EMD with builder pattern let mut emd = EMD::new() .with_max_imfs(5) .with_stopping_criteria(0.2); // Decompose signal into IMFs let imfs = emd.decompose(&signal)?; println!("Original signal length: {}", signal.len()); println!("Number of IMFs: {}", imfs.len()); // Analyze first IMF for heartbeat if !imfs.is_empty() { let heartbeat_imf = &imfs[0]; let energy: f64 = heartbeat_imf.iter() .map(|x| x * x) .sum(); println!("First IMF energy: {:.4}", energy); } Ok(()) }

Key Insights from ECG Decomposition

  • IMF 1: High-frequency noise (50-60 Hz electrical interference)
  • IMF 2-3: Cardiac components (QRS complex, 10-40 Hz)
  • Residual: Baseline drift and T-wave variations
  • Application: Detect arrhythmias by analyzing IMF patterns

🌍 Example 2: Seismic Signal Processing

Process seismic signals to separate earthquake waves (P-waves, S-waves) and background noise. EMD reveals the time-frequency structure of seismic events without assumptions of stationarity. IMF 1-2 contain high-frequency P-waves and surface waves, IMF 3 captures S-waves, and the Residual shows long-period motion.

📊 Seismic Decomposition
From top to bottom: Raw seismic ground displacement → IMF 1 (P-wave high frequencies) → IMF 2 (S-wave and surface waves) → IMF 3 (long-period oscillations) → Residual (permanent displacement and drift).
PythonCopyimport numpy as np from ferromode import EEMD import csv # Load seismic displacement data seismic_data = [] with open('data/seismic_sample.csv') as f: reader = csv.DictReader(f) for row in reader: seismic_data.append(float(row['displacement'])) signal = np.array(seismic_data) # Use Ensemble EMD for better mode separation # Handles noise better than standard EMD eemd = EEMD( num_ensembles=100, # Number of ensemble members noise_std=0.1 # Noise standard deviation ) # Decompose with ensemble method imfs = eemd.decompose(signal) print(f"Number of separated waves: {len(imfs)}") # Identify wave types by energy and frequency for i, imf in enumerate(imfs): energy = np.sum(imf ** 2) fft_result = np.fft.fft(imf) max_freq_idx = np.argmax(np.abs(fft_result)) max_freq = np.fft.fftfreq(len(imf))[max_freq_idx] print(f"Wave {i}: Energy={energy:.6f}, Peak Freq={abs(max_freq):.4f}") # Reconstruct P-waves (typically in first 1-2 IMFs) p_waves = imfs[0] + imfs[1] if len(imfs) > 1 else imfs[0] s_waves = imfs[2] if len(imfs) > 2 else np.zeros(len(signal)) print(f"P-wave energy: {np.sum(p_waves ** 2):.6f}") print(f"S-wave energy: {np.sum(s_waves ** 2):.6f}")
RustCopyuse ferromode::EEMD; use std::fs::File; use csv::Reader; fn main() -> Result<(), Box<dyn std::error::Error>> { // Load seismic data let mut reader = Reader::from_path("data/seismic_sample.csv")?; let mut signal = Vec::new(); for record in reader.records() { let record = record?; let value: f64 = record[1].parse()?; signal.push(value); } // Ensemble EMD decomposition let eemd = EEMD::new() .with_num_ensembles(100) .with_noise_std(0.1); let imfs = eemd.decompose(&signal)?; println!("Separated waves: {}", imfs.len()); // Calculate energy for each IMF for (i, imf) in imfs.iter().enumerate() { let energy: f64 = imf.iter() .map(|x| x * x) .sum(); println!("Wave {}: Energy = {:.6}", i, energy); } Ok(()) }

Seismic Wave Analysis

  • P-waves: Fast, high-frequency (6-14 Hz), arrive first
  • S-waves: Slower, lower frequency (2-8 Hz), arrive second
  • Surface waves: Slowest, very low frequency (<1 Hz)
  • Application: Accurate earthquake location and magnitude estimation

🎵 Example 3: Speech Enhancement & Denoising

Enhance noisy speech by decomposing audio signals and reconstructing with selected IMFs. This technique effectively removes background noise while preserving speech clarity. IMF 1-2 contain high-frequency noise, IMF 3-4 hold speech formants, and the Residual represents the fundamental frequency.

📊 Speech Signal Decomposition
From top to bottom: Noisy speech signal → IMF 1 (high-frequency noise and hiss) → IMF 2 (mid-frequency consonants) → IMF 3 (formant frequencies) → Residual (fundamental frequency and voicing).
PythonCopyimport numpy as np from ferromode import EMD import csv # Load noisy speech signal speech_data = [] with open('data/speech_sample.csv') as f: reader = csv.DictReader(f) for row in reader: speech_data.append(float(row['amplitude'])) noisy_signal = np.array(speech_data) # Decompose speech + noise into components emd = EMD(max_imf=4, stopping_criteria=0.15) imfs = emd.decompose(noisy_signal) # Denoise by reconstructing without high-frequency noise IMFs # Typically, first 1-2 IMFs are noise components num_noise_imfs = 1 clean_signal = np.sum(imfs[num_noise_imfs:], axis=0) # Add residual back to preserve baseline residual = noisy_signal - np.sum(imfs, axis=0) clean_signal += residual # Measure noise reduction effectiveness original_energy = np.sum(noisy_signal ** 2) clean_energy = np.sum(clean_signal ** 2) noise_energy = original_energy - clean_energy print(f"Original energy: {original_energy:.6f}") print(f"Clean energy: {clean_energy:.6f}") print(f"Estimated noise: {noise_energy:.6f}") print(f"SNR improvement: {(clean_energy/noise_energy):.1f}x") # Save clean signal print(f"Clean signal: {len(clean_signal)} samples")
RustCopyuse ferromode::EMD; use std::fs::File; use csv::Reader; fn main() -> Result<(), Box<dyn std::error::Error>> { // Load noisy speech data let mut reader = Reader::from_path("data/speech_sample.csv")?; let mut noisy_signal = Vec::new(); for record in reader.records() { let record = record?; let value: f64 = record[1].parse()?; noisy_signal.push(value); } // Decompose into IMFs let mut emd = EMD::new() .with_max_imfs(4) .with_stopping_criteria(0.15); let imfs = emd.decompose(&noisy_signal)?; // Denoise: reconstruct without first IMF (noise) let clean_signal: Vec<f64> = (0..noisy_signal.len()) .map(|i| { imfs[1..].iter() .map(|imf| imf[i]) .sum() }) .collect(); // Calculate energy metrics let original_energy: f64 = noisy_signal.iter() .map(|x| x * x) .sum(); let clean_energy: f64 = clean_signal.iter() .map(|x| x * x) .sum(); println!("Original energy: {:.6}", original_energy); println!("Clean energy: {:.6}", clean_energy); println!("Denoising ratio: {:.1}x", clean_energy / (original_energy - clean_energy)); Ok(()) }

Speech Signal Components

  • Noise IMFs: High-frequency (first 1-2 IMFs, >4 kHz)
  • Formants: Mid-frequency (speech info, 500-4000 Hz)
  • Fundamental: Low-frequency voicing (<500 Hz)
  • Application: Remove background noise in calls, improve voice clarity

💰 Example 4: Financial Time Series Analysis

Analyze stock prices and financial data to separate long-term trends from short-term fluctuations. Use EMD for feature extraction in predictive models. IMF 1-2 capture high-frequency trading noise and intraday volatility, IMF 3 shows medium-term oscillations, and the Residual represents the primary trend.

📊 Financial Time Series Decomposition
From top to bottom: Stock price time series → IMF 1 (high-frequency trading volatility and noise) → IMF 2 (medium-frequency price fluctuations) → IMF 3 (intermediate oscillations) → Residual (long-term trend and market direction).
PythonCopyimport numpy as np from ferromode import EMD import csv # Load financial data prices = [] dates = [] with open('data/finance_sample.csv') as f: reader = csv.DictReader(f) for row in reader: dates.append(row['date']) prices.append(float(row['price'])) price_signal = np.array(prices) # Decompose price into trend and fluctuations emd = EMD(max_imf=4, stopping_criteria=0.2) imfs = emd.decompose(price_signal) print(f"Price decomposed into {len(imfs)} components") # Separate trend from trading signals # Fast IMFs contain trading signals, residual is long-term trend trading_signals = np.sum(imfs[:-1], axis=0) # Fast IMFs trend = imfs[-1] # Residual (trend) # Identify crossover points for trading signals signal_diff = np.diff(trading_signals) crossovers = np.where((signal_diff[:-1] * signal_diff[1:] < 0))[0] print(f"Trend: min=${trend.min():.2f}, max=${trend.max():.2f}") print(f"Trading signals: {len(crossovers)} crossover points") # Calculate volatility from high-frequency IMF volatility = np.std(imfs[0]) if len(imfs) > 0 else 0 print(f"Market volatility (IMF1): {volatility:.4f}") # Feature extraction for ML models trend_slope = np.polyfit(range(len(trend)), trend, 1)[0] signal_var = np.var(trading_signals) print(f"Trend slope: {trend_slope:.6f} ($/day)") print(f"Signal variance: {signal_var:.6f}")
RustCopyuse ferromode::EMD; use std::fs::File; use csv::Reader; fn main() -> Result<(), Box<dyn std::error::Error>> { // Load stock price data let mut reader = Reader::from_path("data/finance_sample.csv")?; let mut prices = Vec::new(); for record in reader.records() { let record = record?; let price: f64 = record[1].parse()?; prices.push(price); } // Decompose prices into trend and components let mut emd = EMD::new() .with_max_imfs(4) .with_stopping_criteria(0.2); let imfs = emd.decompose(&prices)?; println!("Decomposed into {} components", imfs.len()); // Extract trend from last IMF (residual) if let Some(trend) = imfs.last() { let min = trend.iter().cloned().fold(f64::INFINITY, f64::min); let max = trend.iter().cloned().fold(f64::NEG_INFINITY, f64::max); println!("Trend: min=${:.2}, max=${:.2}", min, max); } // Calculate volatility from first IMF if !imfs.is_empty() { let mean: f64 = imfs[0].iter().sum::f64() / imfs[0].len() as f64; let variance: f64 = imfs[0].iter() .map(|x| (x - mean).powi(2)) .sum::f64() / imfs[0].len() as f64; println!("Market volatility: {:.4}", variance.sqrt()); } Ok(()) }

Financial Signal Components

  • IMF 1-2: High-frequency noise and trading (second/minute scale)
  • IMF 3: Medium-term oscillations (hours/days scale)
  • Residual: Long-term trend (weeks/months scale)
  • Application: Build predictive models with separated trend and cycle components
