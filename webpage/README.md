# Ferromode Website

This directory contains the static website for the Ferromode project. The website is built with pure HTML, CSS, and JavaScript—no external dependencies or build tools required.

## Directory Structure

```
webpage/
├── index.html              Home page with hero section and features
├── about.html              About EMD and Ferromode versions
├── docs.html               Getting started and API documentation
├── examples.html           Real-world code examples with SVG visualizations
├── css/
│   └── style.css          Responsive design with code highlighting & visualizations
├── js/
│   └── main.js            Navigation, tabs, FAQ accordion, download handlers
├── images/
│   ├── ferromode2.png           Project logo
│   ├── ecg_decomposition.svg      EMD visualization for ECG signals
│   ├── seismic_decomposition.svg  EMD visualization for seismic signals
│   ├── speech_decomposition.svg   EMD visualization for speech signals
│   └── finance_decomposition.svg  EMD visualization for financial time series
├── data/
│   ├── ecg_sample.csv     ECG signal sample data (50 samples)
│   ├── seismic_sample.csv Seismic signal sample data (40 samples)
│   ├── speech_sample.csv  Speech signal sample data (40 samples)
│   └── finance_sample.csv Financial time series sample data (31 samples)
├── generate_visualizations.py  Script to regenerate SVG decomposition plots
└── README.md              This file
```

## Development

### No Build Tools Required
The website is pure HTML/CSS/JavaScript. To run locally:

```bash
# Option 1: Simple Python server
python3 -m http.server 8000
# Visit http://localhost:8000

# Option 2: Simple Node.js server
npx http-server
# Visit http://localhost:8080

# Option 3: Live Server (VS Code extension)
# Right-click index.html → Open with Live Server
```

### Regenerating SVG Visualizations
To regenerate the SVG decomposition charts (e.g., after modifying sample data):

```bash
cd webpage
python3 generate_visualizations.py
```

This will:
1. Load sample data from `data/*.csv` files
2. Simulate EMD decomposition
3. Generate SVG files in `images/`
4. Overwrite existing visualizations

To use with your own data:
- Replace CSV files in `data/` directory
- Ensure CSV has numeric values in first or second column
- Run the script to generate new charts

### CSS Customization
Edit `css/style.css` to modify:
- **Colors:** Edit CSS variables at the top (`:root` section)
- **Typography:** Modify font sizes and weights
- **Spacing:** Adjust padding and margins
- **Code Blocks:** Customize syntax highlighting colors (.keyword, .string, .comment, etc.)
- **Visualizations:** Modify .visualization-container and .visualization-svg styles
- **Animations:** Modify `@keyframes` and transitions

### JavaScript Functionality
Edit `js/main.js` to:
- Add new interactive features
- Modify navigation behavior
- Update tab system logic
- Enhance FAQ accordion
- Customize data downloads

## Deployment

### GitHub Pages (Automatic)
The website is automatically deployed to GitHub Pages via the GitHub Actions workflow in `.github/workflows/deploy-website.yml`.

To enable:
1. Go to GitHub repository Settings
2. Navigate to Pages
3. Select "Deploy from a branch"
4. Choose `main` branch and `/root` (or `/docs` if preferred)
5. Save

The workflow will:
- Run on every push to `main`
- Build static assets (if needed in future)
- Deploy `webpage/` directory to GitHub Pages
- Make the site available at `https://username.github.io/ferromode/`

### Manual Deployment
To deploy to any static hosting:

1. **Netlify:**
   - Connect GitHub repository
   - Set publish directory to `webpage/`
   - Deploy

2. **Vercel:**
   - Import from GitHub
   - Set root directory to `webpage/`
   - Deploy

3. **AWS S3 + CloudFront:**
   - Upload contents of `webpage/` to S3
   - Set up CloudFront distribution
   - Point domain to CloudFront

4. **Traditional Hosting:**
   - Upload contents of `webpage/` via FTP/SFTP
   - No build process needed
   - Ready to serve immediately
