Getting Started

Python Installation

pip install ferromode

Python Quick Start

import numpy as np from ferromode import EMD # Create sample signal signal = np.sin(2 * np.pi * 0.1 * np.arange(1000)) + \ 0.5 * np.sin(2 * np.pi * 0.05 * np.arange(1000)) # Decompose signal emd = EMD() imfs = emd.decompose(signal) # Access individual IMFs print(f"Number of IMFs: {len(imfs)}") for i, imf in enumerate(imfs): print(f"IMF {i}: shape={imf.shape}")

Rust Quick Start

Add to Cargo.toml: [dependencies] ferromode = "2.7" In src/main.rs: use ferromode::EMD; fn main() { let signal: Vec<f64> = vec![/* ... */]; let mut emd = EMD::new(); let imfs = emd.decompose(&signal); println!("Number of IMFs: {}", imfs.len()); }

Core Concepts

Intrinsic Mode Functions (IMFs)

IMFs are the fundamental components extracted by EMD. Each IMF represents oscillations at a specific timescale. The algorithm iteratively extracts IMFs from high to low frequency.

The Sifting Process

The sifting process is the heart of EMD. It extracts IMFs by:

  1. Finding all local maxima and minima in the signal
  2. Interpolating upper and lower envelopes
  3. Computing the mean of the envelopes
  4. Subtracting the mean from the signal
  5. Repeating until convergence (stopping criteria met)

Stopping Criteria

Sifting stops when the Standard Deviation (SD) between consecutive iterations falls below a threshold:

SD = sum((h_i - h_{i-1})^2) / sum(h_{i-1}^2) SD < threshold (default: 0.2)

Decomposition Completion

The algorithm stops extracting IMFs when the remaining signal becomes a monotonic function or has less than 3 extrema.

API Overview

Python API

EMD Class Methods

decompose(signal, **kwargs)

Decompose a signal into Intrinsic Mode Functions.

Parameters: signal (array-like), max_imf (int), stopping_criteria (float)

Returns: List of IMF arrays

fit(signal)

Fit the EMD model to a signal (for ensemble methods).

Parameters: signal (array-like)

Returns: self

get_imfs()

Get the IMFs from the last fit.

Returns: List of IMF arrays

Rust API

pub struct EMD { max_imfs: usize, stopping_criteria: f64, } impl EMD { pub fn new() -> Self pub fn decompose(&mut self, signal: &[f64]) -> Result<Vec<Vec<f64>>, Error> pub fn with_max_imfs(mut self, max_imfs: usize) -> Self }

Configuration & Parameters

Algorithm Parameters

max_imf

Maximum number of IMFs to extract. Default: unlimited

stopping_criteria

SD threshold for stopping sifting. Default: 0.2 (range: 0.1-0.5)

interpolation_method

Envelope interpolation method: 'cubic' or 'linear'. Default: 'cubic'

num_extrema_stop

Minimum number of extrema to continue. Default: 3

Ensemble Parameters (for V2.1, V2.6, V2.7)

num_ensembles

Number of ensemble iterations. Default: 100

noise_std

Standard deviation of Gaussian noise. Default: 0.2

num_threads

Parallel processing threads. Default: number of CPU cores

Time Complexity

Ferromode uses adaptive sifting with optimized envelope interpolation:

  • Standard EMD: O(n log n) average case
  • Ensemble methods: O(n log n × num_ensembles)
  • Parallelization: Near-linear speedup with CPU cores

Frequently Asked Questions

What's the difference between EMD versions?

▼

Different versions optimize for different use cases. V2.0 is the classic algorithm, V2.1 is better for noisy signals, V2.3 prioritizes speed, and V2.6-V2.7 handle mode mixing better. See the About page for detailed version comparisons.

How do I choose the right stopping criteria?

▼

The default value of 0.2 works well for most signals. Lower values (0.1) produce more detailed decompositions but take longer. Higher values (0.3-0.5) are faster but may miss fine details. Start with the default and adjust based on your results.

Can EMD handle non-stationary signals?

▼

Yes! That's one of EMD's key advantages. Unlike Fourier analysis, EMD doesn't assume stationarity and can analyze signals whose frequency content changes over time. This makes it ideal for real-world signals.

What does "mode mixing" mean?

▼

Mode mixing occurs when a single IMF contains oscillations at very different scales, or when oscillations of similar scale are distributed into different IMFs. Ensemble methods (V2.1, V2.6, V2.7) reduce mode mixing by adding controlled noise.

Is EMD suitable for real-time applications?

▼

For short windows (up to ~10,000 samples), yes. Use V2.3 (Fast EMD) or standard V2.0 with optimized parameters for real-time performance. For very long streams, consider buffering and processing in overlapping segments.

How do I interpret the IMFs?

▼

IMFs are ordered from highest to lowest frequency. The first IMF contains the fastest oscillations, and each subsequent IMF represents slower variations. The final residual is the trend. Each IMF can be analyzed separately for features or used to reconstruct the original signal.
